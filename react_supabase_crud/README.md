# CRUD React + Supabase

1. Crea un proyecto en Supabase y ejecuta `supabase.sql` en el SQL Editor (crea la tabla `items` con politicas RLS).
2. Pon tu Project URL y anon key en `.env` (`VITE_SUPABASE_URL`, `VITE_SUPABASE_KEY`).
3. `npm install` y `npm run dev`.

Estructura: `src/supabase-client.js` (cliente), `src/api.js` (CRUD), `src/App.jsx` + `src/ItemForm.jsx` (UI).
